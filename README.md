# Tugas Slicing Website

## Deskripsi

Website ini merupakan tugas slicing website yang dibuat berdasarkan desain tampilan yang telah ditentukan. Website dibuat menggunakan HTML, CSS, dan JavaScript tanpa menggunakan framework seperti Bootstrap atau Tailwind.

Website memiliki tampilan sederhana dengan tema islami dan menampilkan sebuah kutipan ayat Al-Qur'an.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- Responsive Design

## Fitur

- Tampilan responsive untuk desktop, tablet, dan mobile
- Background menggunakan gambar
- Tampilan kutipan ayat Al-Qur'an
- Tombol Baca di Al-Qur'an
- Tombol pengaturan teks
- Navigasi Beranda, Tema, dan Aplikasi
- Progress sederhana, ketika pencet baca Al-quran akan nambah progres diatas (0-5)
